# just volleyball 日本語化MOD

Windows用の非公式MODです。

## 導入方法

1. ゲームを終了します。
2. [最新Release](https://github.com/AkioPonkotu/JustVolleyballInJapanese/releases/latest)の[JustVolleyballJA.exeをダウンロード](https://github.com/AkioPonkotu/JustVolleyballInJapanese/releases/latest/download/JustVolleyballJA.exe)します。
3. exeを起動し、自動入力されたゲームフォルダーを確認して「日本語化を適用 →」を押します。

フォルダーが見つからない場合：Steamでゲームを右クリック →「管理」→「ローカルファイルを閲覧」で開く場所を、exeの「参照…」から選んでください。

解除はゲーム終了後、同じexeの「元に戻す」から。
MOD更新時は先に解除してください。
