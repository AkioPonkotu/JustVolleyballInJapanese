## 再実行

元PCK・EXE・Steam DLLのコピーを `work/build/original-game/` に用意してから：

```powershell
uv run --python 3.12 --with-requirements requirements-build.txt python tools/build_patch.py --game-dir work/build/original-game
uv run --python 3.12 --with-requirements requirements.txt python tools/patch_game.py --game-dir work/build/original-game --package dist/just-volleyball-ja --output work/build/menu-layout-fixed.pck
uv run --python 3.12 --with-requirements requirements.txt python tools/measure_menu_layout.py --patched-pck work/build/menu-layout-fixed.pck --output evidence/menu-layout-fixed.json
```

出力PCKのパスは既存ファイルと重複しないものにする。
診断は独立したPCKとユーザーディレクトリを使い、通常のゲーム初期化やオンライン参加処理を呼ばない。
パーティー参加中の表示はテスト用の6人枠で再現し、実際のオンライン通信は行っていない。
測定結果は `evidence/menu-layout-fixed.json`。
検証はヘッドレスでの組版測定で、実画面の目視確認・実対戦は含まない。
