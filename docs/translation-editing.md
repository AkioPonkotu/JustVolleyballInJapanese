# 翻訳の編集とパッチの再生成

## 人が編集するファイル

`translations/ja/` の用途別JSONが翻訳の正本です。生成したPCK、差分ファイル、復元コードを編集する必要はありません。

| ファイル | 内容 |
| --- | --- |
| `ui.json` | メニュー、試合表示、各種共通ラベル |
| `settings.json` | 設定項目と説明 |
| `tutorial.json` | チュートリアルの本文と操作プロンプト |
| `howto.json` | 遊び方の全表示フィールド。文脈ごとに別ID |

各項目は次の形です。

```json
"ui.（固定のID）": {
  "source": "play",
  "ja": "プレイ",
  "status": "draft",
  "note": ""
}
```

編集するのは `ja`、`status`、`note` です。原文 `source`、ID、遊び方の位置を指定する `context` は変更しないでください。原文と文脈から決めたIDは、人が訳を何度直しても変わりません。

- `draft`: 初稿・確認待ち。パッチへ収録します。
- `reviewed`: 人によるレビュー済み。パッチへ収録します。
- `obsolete`: 収録から除外します。ただし遊び方の203フィールドを欠くとビルドは失敗します。
- `note`: 表記の理由、相談事項、確認履歴などを自由に記入できます。ゲーム画面には表示されません。

JSONはUTF-8、改行LFで管理します。訳文に改行を入れるときは `\n`、引用符は `\"` を使います。複数人では用途別に担当を分けると、Gitの競合が少なくなります。

## 壊してはいけない部分

`%s`、`%d`、`%.1f` 等は差し込み文字です。数と順番を保持してください。`{jump}`、`{kb:contact}`、`{pad:move}` 等は操作アイコンなので、綴りを変えずに残します。これらのトークン自体は翻訳しません。位置は自然な日本語になるように動かせます。

`[b]...[/b]` 等の装飾タグも保持します。検証ツールは差し込み文字とタグの欠落・追加、数値書式の順序変更、空の訳文、原文やIDの変更、同じメッセージへの相反する訳を検出してビルドを止めます。ゲーム中の内部ID、操作名、データのキーは変更しません。

遊び方は同じ英語でも文脈によって意味が異なるため、JSON Pointerを持つ別項目にしています。例えば `setting` は「トス」と「設定」を別々に編集できます。通常UIの共有メッセージに文脈違いが必要になった場合は、メッセージを重複定義せず、コード側の個別対応を追加してください。

## 検証・参照情報の更新

```powershell
Set-Location 'F:\Github\JustVolleyballInJapanese'
uv run --python 3.12 python tools/catalog.py validate
uv run --python 3.12 python tools/catalog.py sync
```

`sync` は現在の抽出結果から `translations/source-locations.json` を再生成します。訳文、レビュー状態、メモ、項目の順番には触れません。行番号の変化は参照ファイルだけの差分になります。

未収録の候補は `work/analysis/untranslated-candidates.json` に出します。候補には内部キーやログも混ざっているため、これを無条件に翻訳することは避けてください。

新たな文言は原文→訳文のJSONを一時ファイルに書いて追加できます。

```powershell
uv run --python 3.12 python tools/catalog.py import --domain ui --seed work/new-translations.json
```

インポートは新しいIDだけを追加します。既存IDの訳・状態・メモは、入力側に別の値があっても上書きしません。既存訳の修正は正本のJSONで行ってください。

## ビルド

このリポジトリでは、解析済みの `work/raw` / `work/recovered` と `.local/gdre/gdre_tools.exe` が利用できます。別環境では先に `docs/pck-analysis.md` のローカル解析を行い、GDRE Tools v2.7.4を用意してください。

```powershell
uv run --python 3.12 --with-requirements requirements.txt python tools/build_patch.py
```

出力は `dist/just-volleyball-ja.zip` とその展開内容です。人の訳文を検証してから再生成します。原文の位置、対象ビルド、差分の元ハッシュが一致しなければ停止します。

差し込み文字を含む文は、書式を展開する前に翻訳します。通常のLabel/Buttonは翻訳辞書を使用し、遊び方は表示フィールドのみを書き換えます。チュートリアルとGuideTokensの独自描画には翻訳処理を追加しています。ユーザー名やチャットを走査して機械的に置換する処理はありません。

ZIPには変更リソースのバイナリ差分、翻訳辞書、日本語フォント、適用・解除ツールを収録します。元の全PCK、復号鍵、ゲームEXE、復元したゲームの全ソースは収録しません。

## ゲーム更新への対応

現在はBuild ID 26937150専用です。異なるビルドへの適用は拒否します。更新後の抽出結果を正本に直接上書きすることはしません。まず新規・変更・削除された原文を比較し、訳を引き継ぐか人が判断してください。出典行番号はIDに使わず、原文が同じ項目は再抽出でも同じIDを維持できます（遊び方は文脈位置も含みます）。

旧項目は削除せず `obsolete` にして履歴を残せます。ビルドのハッシュやコードへの差し込み位置は、実機検証後に更新します。
